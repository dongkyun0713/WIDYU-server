# LLD-0030: 복약 인증 사진 S3 삭제 영속 재시도

| 항목 | 값 |
| --- | --- |
| 상태 | Approved |
| Issue | #599 |
| 관련 ADR | ADR-0025 |
| 작성일 | 2026-09-13 |

## 1. 목적 / 배경

회원 탈퇴 뒤 복약 인증 사진의 S3 삭제가 일시적으로 실패해도, DB에서 삭제된 인증 데이터와 분리해 안전하게 재시도한다. S3 호출 실패가 탈퇴를 되돌리거나 사진 URL 원문을 로그에 남기지 않게 한다.

## 2. 범위

### In scope

- 변경 모듈: widyu-domain, widyu-api
- 탈퇴 트랜잭션 안에서 사진별 삭제 작업을 저장한다.
- 커밋 뒤 최초 삭제를 시도하고, 실패 작업을 5분 주기로 최대 5회 처리한다.
- 성공·실패 종료 상태와 시도 횟수, 다음 시각, 오류 유형을 보존한다.
- 여러 서버와 최초 이벤트가 같은 작업을 처리하지 않도록 짧은 DB 트랜잭션에서 작업을 선점한다.

### Out of scope

- 앨범·프로필 등 복약 인증 이외 미디어 삭제 작업
- 완료·실패 작업의 보존 기간과 관리 화면
- S3 URL 또는 객체 키의 별도 암호화

## 3. 인터페이스 / API

공개 API 계약은 바꾸지 않는다. `DELETE /api/v1/auth/guardians/withdraw` 응답은 기존과 같고, 작업 큐는 내부 처리만 한다.

## 4. 데이터 모델

`medication_proof_image_deletion_task`를 추가한다. `member_id`, `object_key`, `status(PENDING/PROCESSING/COMPLETED/FAILED)`, `retry_count`, `processing_attempt`, `lease_expires_at`, `next_retry_at`, `last_error_type`, `completed_at`, `failed_at`을 보관한다. `status, next_retry_at` 복합 인덱스로 재시도 대상을 조회한다.

## 5. 처리 흐름

1. 탈퇴 트랜잭션에서 사진 URL을 객체 키로 변환해 작업을 저장하고 인증 레코드를 삭제한다.
2. 커밋 뒤 이벤트 리스너와 스케줄러는 짧은 새 트랜잭션에서 `PENDING` 작업을 `PROCESSING`으로 원자적으로 선점한다. 선점에는 10분 임대를 부여한다.
3. S3 삭제는 트랜잭션 없이 실행한다. 결과는 행을 짧게 잠근 새 트랜잭션에서 선점 시 발급된 `processing_attempt`가 일치할 때만 반영한다.
4. S3 삭제가 성공하면 `COMPLETED`로 기록한다.
5. 실패하면 시도 횟수를 증가시키고 5분 뒤 재예약한다. 5번째 실패면 `FAILED`로 종료한다.
6. 스케줄러는 5분마다 처리 시각이 지난 `PENDING` 작업과 임대가 만료된 `PROCESSING` 작업을 최대 100건 처리한다.

## 6. 예외 / 에러 처리

- 객체 키를 얻을 수 없는 URL은 작업을 만들지 않고 URL 원문 없이 회원 ID·실패 건수만 오류 로그에 기록한다.
- S3 실패는 탈퇴 API 실패로 전파하지 않는다.
- S3 삭제 결과의 오류 클래스와 처리 예외의 클래스명만 `last_error_type`에 기록한다.

## 7. 인수조건

- [ ] 탈퇴 트랜잭션이 롤백되면 삭제 작업과 S3 삭제가 모두 발생하지 않는다.
- [ ] 커밋 후 최초 S3 삭제 성공 시 작업은 `COMPLETED`가 된다.
- [ ] S3 삭제 실패 시 작업은 재시도 횟수와 다음 시각을 보존한 `PENDING` 상태가 된다.
- [ ] 5회 실패한 작업은 `FAILED` 상태가 되고 이후 스케줄러 대상에서 제외된다.
- [ ] 같은 작업을 동시에 처리하려 해도 한 작업자만 선점하며, 임대가 만료된 작업만 회수한다.
- [ ] 이전 선점자의 늦은 결과는 새 선점자의 작업 상태를 덮어쓰지 않는다.
- [ ] 로그와 작업 테이블에 URL 원문을 저장하지 않는다.

## 8. 영향 범위 / 마이그레이션

운영 DB는 `ddl-auto: validate`이므로 배포 전에 `scripts/mysql/create_medication_proof_image_deletion_task.sql`을 실행한다.

## 9. 미결정 사항 (Open Questions)
