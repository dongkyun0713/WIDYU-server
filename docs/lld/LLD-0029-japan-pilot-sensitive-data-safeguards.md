# LLD-0029: 일본 실증 민감정보 보호 장치

| 항목 | 값 |
| --- | --- |
| 상태 | Approved |
| Issue | #595 |
| 관련 ADR | ADR-0025 |
| 작성자 | Codex |
| 작성일 | 2026-09-13 |

## 1. 목적 / 배경

일본 실증에서 복약·건강·위치 정보가 운영 로그에 원문으로 남거나, 회원 탈퇴 뒤에도 복약 인증 사진이 남지 않게 한다. 기존 API 계약을 유지하면서 서버 로그와 탈퇴 처리에서 즉시 줄일 수 있는 노출 범위를 제거한다.

## 2. 범위

### In scope

- 변경 모듈: widyu-api
- 탈퇴 사유와 OAuth 식별자, 위치 좌표·주소, 약품 검색어를 로그에 기록하지 않는다.
- 회원 탈퇴 시 해당 회원의 복약 인증 사진을 S3에서 삭제하고 인증 레코드를 삭제한다.
- 운영 환경에서 MySQL·Redis TLS 사용 여부를 명시적으로 설정할 수 있게 한다.

### Out of scope

- 이름·전화번호·이메일의 결정적 암호화 또는 blind index 전환
- 기존 데이터 전체 백필과 백업·스냅샷의 파기
- 건강·위치 처리 동의 화면 및 모바일 클라이언트 연동
- 앨범·프로필 미디어의 탈퇴 시 파기. 가족 공유 데이터의 보존 정책을 먼저 확정해야 한다.

## 3. 인터페이스 / API

공개 API 계약은 변경하지 않는다. 회원 탈퇴 API `DELETE /api/v1/auth/guardians/withdraw`의 성공 응답은 유지하며, 탈퇴 처리 중 복약 인증 사진과 레코드를 함께 삭제한다.

## 4. 데이터 모델

`medication_proof`와 `medication_proof_images`의 해당 회원 레코드를 삭제한다. 신규 테이블과 컬럼은 추가하지 않는다.

## 5. 처리 흐름

1. 탈퇴 요청에서 방장 위임 여부를 먼저 검증한다.
2. 인증 사진 URL을 조회하고 S3 객체를 삭제한다.
3. 인증 레코드를 삭제한 뒤 기존 토큰 폐기·소셜 연결 해제·개인 식별자 마스킹을 수행한다.
4. S3 삭제가 실패하면 탈퇴를 중단하지 않고, 실패한 URL 원문 없이 회원 ID와 삭제 실패 개수만 오류 로그에 기록한다.
5. 민감값을 받는 서비스 로그는 대상 ID·건수·결과만 기록한다.

## 6. 예외 / 에러 처리

- 복약 인증 레코드 삭제 실패: `INTERNAL_SERVER_ERROR`로 탈퇴 트랜잭션을 중단한다.
- S3 객체 삭제 실패: 탈퇴는 계속 진행하며 오류 로그에 대상 회원 ID와 실패 건수만 남긴다.

## 7. 인수조건 (Acceptance Criteria)

- [ ] 탈퇴 사유와 OAuth 식별자가 애플리케이션 로그 메시지에 포함되지 않는다.
- [ ] 위치 좌표·약품 검색어가 애플리케이션 로그 메시지에 포함되지 않는다.
- [ ] 회원 탈퇴 시 복약 인증 사진 삭제를 시도하고 인증 레코드를 삭제한다.
- [ ] S3 사진 삭제 실패가 탈퇴 처리를 막지 않으며 원문 URL을 로그에 남기지 않는다.
- [ ] 운영 MySQL·Redis TLS 설정이 환경변수로 제어된다.
- [ ] Swagger 공개 계약은 변경하지 않는다.
- [ ] `./gradlew :backend:widyu-api:test`가 통과한다.

## 8. 영향 범위 / 마이그레이션

기존 테이블과 API 스키마는 변경하지 않는다. 운영 환경변수 `MYSQL_SSL_MODE`, `REDIS_SSL_ENABLED`를 배포 설정에 추가한다. RDS TLS에는 `MYSQL_SSL_MODE=VERIFY_IDENTITY`와 신뢰 저장소의 RDS CA를 사용한다. Redis가 TLS를 제공하도록 먼저 구성한 뒤 `REDIS_SSL_ENABLED=true`를 설정한다.
