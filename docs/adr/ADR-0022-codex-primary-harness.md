# ADR-0022: Codex를 주 구현 에이전트로 사용하는 공통 하네스

| 항목 | 값 |
| --- | --- |
| 상태 | Accepted |
| 날짜 | 2026-09-07 |
| 관련 | #549, LLD-0026 |

## 맥락 (Context)

기존 Codex 지침은 CLAUDE.md를 다시 읽게 하고 implement/review 스킬은 Claude가 구현한다는 전제를 가진다. Claude 훅의 정적 검사·컴파일·Codex 리뷰는 Codex 작업에는 연결되지 않는다. LLD 예외를 허용하는 docs/lld/README.md와 구현 스킬의 무조건 중단 규칙도 충돌한다.

## 결정 (Decision)

- 루트 AGENTS.md를 공통 진입점으로, backend/admin의 AGENTS.md를 작업 영역 규칙으로 사용한다. CLAUDE.md는 해당 AGENTS.md를 불러오는 호환 진입점으로 남긴다.
- ADR → LLD → 테스트 시나리오 → 구현 → 검수 흐름을 유지한다. 문서 필요 여부는 기존 docs/adr 및 docs/lld의 작성 기준에 따른다. 필요한 설계는 에이전트가 작성하고, 사용자 결정이 필요한 정책만 질문한다.
- .agents/skills를 공통 스킬 원본으로 유지하고 Codex 구현·작업 트리 리뷰를 기본 경로로 바꾼다. 이미 받은 작업 권한을 반복 확인하지 않는다.
- 에이전트와 무관한 검증 명령을 제공한다. HEAD 또는 명시한 base 대비 staged/unstaged/untracked 변경을 포함하고, domain 변경은 API 소비자 테스트도 실행한다. 실패 종료 코드를 그대로 전달한다.
- 설치된 Codex CLI 0.153.4 및 공식 문서에서 확인한 inline hooks를 사용한다. Bash는 기존 명령 가드를 재사용한다. apply_patch는 보호 브랜치를 차단하고, 작업 브랜치도 세션 최초 편집 전에 현재 요청과 브랜치의 작업이 같은지 확인하는 세션×브랜치 ack를 요구한다. Stop은 정적 검사만 수행하며 Codex를 다시 호출하지 않는다. 전체 검증은 명시적 완료 절차와 CI가 담당한다.
- 모델·개인 권한·MCP 자격증명은 사용자 설정에 둔다. 기존 Figma MCP 연결은 보존한다. 훅 신뢰는 사용자가 Codex의 /hooks에서 설정한다.

## 고려한 대안 (Considered Options)

1. **CLAUDE.md를 fallback으로 등록** — 수정량이 적지만 지침 소유권·중복 문제와 Claude 전용 실행 전제가 남는다.
2. **Claude Stop 전체를 Codex에 연결** — 재사용이 쉽지만 다른 입력 형식·세션 상태·중첩 Codex 호출·실패 후 통과 정책까지 이전하게 된다.
3. **지침 + 공통 검사 + 얇은 Codex 훅** — 훅 어댑터 검증이 필요하지만 공통 검증을 로컬과 CI에서 재사용할 수 있다. 이를 채택한다.

## 결과 (Consequences)

### 긍정
- 도메인·테스트 지침을 한 곳에서 유지하며 Claude도 계속 사용할 수 있다.
- 자동 검사와 의미 검수의 책임을 구분하고, 실패나 미실행을 성공으로 보고하지 않는다.

### 부정 / 트레이드오프
- Codex 훅의 신뢰 설정과 클라이언트 지원 여부를 확인해야 한다. 훅이 비활성인 환경에서도 공통 검증 명령을 직접 실행해야 한다.
- 세션×브랜치 ack는 새 세션이나 브랜치 전환 시 작업 혼입을 막는다. 같은 세션·브랜치에서 사용자가 별개의 새 작업을 요청하는 경우에는 의미를 자동 판별하지 못하므로 AGENTS.md와 issue 스킬을 함께 적용한다.
- apply_patch 브랜치 가드는 셸이나 외부 도구의 모든 파일 쓰기를 강제하지 않는다. 명령 가드도 사고 방지 장치이며 보안 경계가 아니다. AGENTS.md, .gitignore 역시 파일 접근 제어가 아니다.
- Stop의 정적 검사는 컴파일·테스트·인수조건 검수를 대체하지 않는다. 같은 턴의 반복 차단은 stop_hook_active로 제한하고 미해결 결과를 보고한다.

## 후속 / 미결정

기존 #526(Claude rules), #527(Claude Stop 테스트), #538(조건부 리뷰)의 공통 문제를 참고했다. 해당 이슈와 Claude 전용 훅은 자동 종료·삭제하지 않는다. ADR-0018의 Claude 권한 결정은 Claude 경로에 유지한다. ADR-0021의 세션×브랜치 ack 원칙은 Codex 입력 형식에 맞춰 `.codex/state`에 별도로 적용한다.

출처와 실제 적용 방법은 [Codex 하네스 운영 가이드](../harness/codex.md)에 기록한다.
