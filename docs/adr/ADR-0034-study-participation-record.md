## 맥락 (Context)

국내 실증 자료는 서면 연구동의·선택 동의·철회 상태·보관 계획을 사람 단위로 추적해야 한다(정책서 1.5.1·1.5.3). 연구 참여 등록 모델(#617, ADR-0026)은 2026-09-18에 폐기됐고, 그 뒤 `collection_run`이 study_id·participation_id·동의 판·보관 날짜를 요청값으로 중복 저장해 왔다. 어느 값이 정본인지 없고, 참여 기록 없이 연구 회차를 열 수 있으며, 철회 시 「한 사람 자료를 무엇으로 찾는가」(1.5.8 선행 조건 ②)에 답이 없었다.

사용자는 2026-09-20에 참여 기록을 되살리되 ADR-0026과 다른 조건을 정했다. 서버 발급 식별자, 서면 동의는 관리자 API로 입력, 선택 동의 항목별 예/아니오, 보관 날짜는 IRB 승인 전까지 비워 둠, 변경은 이력만 남김, 자동 삭제 없음, 실증 기간 삭제는 수동.

## 결정 (Decision)

1. **한 행 = 한 사람의 실증 참여 한 번.** `study_participation`에 서버 발급 `participation_id`(`part-` + UUID), study_id, member_id, 동의서 판·서명일, 상태(ACTIVE/ENDED/WITHDRAWN), 철회 일시·범위·수동 처리 완료 일시, 보관 날짜 셋·data_policy를 둔다. 선택 동의와 일부 철회 항목은 자식 테이블이다. 이름·전화번호는 넣지 않는다. 실명 대응표는 서버 밖이다.
2. **보관 날짜는 비워도 등록·수집한다.** 「없으면 수집 거부」(1.5.3)는 실증 기간에 완화한다(대표 결정, 질의 ①). 날짜를 넣을 때는 셋 전부, 순서 검증.
3. **변경은 불변 snapshot 이력으로 남긴다.** `study_participation_history`가 등록·보관 계획 변경·철회·처리 완료마다 정책·상태·철회 항목을 복사한다. 「누가」는 기존 관리자 감사 로그가 답하고, 「무엇이 바뀌었나」는 이력이 답한다. ADR-0026의 「감사 로그만으로 충분」은 보관 계획 원문을 복원할 수 없어 기각한다.
4. **연구 회차는 참여 기록을 FK로 참조하고 요청값을 신뢰하지 않는다.** `collection_mode=research`는 대상 회원의 ACTIVE 참여 기록 없이 열 수 없다. 연구 메타데이터는 엔티티 getter가 FK 우선으로 읽는다. `collection_run`의 중복 컬럼은 새 회차에서 쓰지 않으며 백필 뒤 별도 승인으로 지운다.
5. **철회는 상태만 바꾼다. 삭제는 수동이다.** participation_id → 회차 → 배치(S3 키)·심박·위치·하트비트·판정 기록이 run_id로 이어지므로 한 식별자로 찾는다. 자동 가명화·파기 스케줄러는 만들지 않는다(사용자 결정 2026-09-20, #651과 같은 원칙).
6. **ACTIVE 단일성은 DB 제약이다.** 같은 study_id+member_id의 ACTIVE 행은 하나만 허용하고, 서비스 조회는 빠른 응답용이다.

## 고려한 대안 (Considered Options)

1. **ADR-0026 그대로 부활** — 클라이언트 발급 ID, 필수 보관값, 자동 가명화·삭제. 사용자 조건과 셋 다 어긋난다. 기각.
2. **collection_run에 그대로 두기** — 회차마다 동의·보관값을 다시 적으면 한 사람의 정책이 회차 수만큼 갈라진다. 기각.
3. **이력 없이 감사 로그만** — 보관 계획 원문·철회 항목을 복원 못 한다. 기각.
4. **인앱 서비스 동의와 한 테이블** — 서비스 동의는 일반 사용자도 쓰고 인앱에서 받는다(1.5.10). 섞지 않는다.

## 결과 (Consequences)

### 긍정
- 실증 참가자와 일반 사용자가 참여 기록 유무로 구분된다. 실증 규칙은 참여 기록에 묶인 자료에만 적용된다.
- 철회 범위 찾기가 식별자 하나로 된다(1.5.8 ②).

### 부정 / 트레이드오프
- 관리자가 서면 동의를 손으로 입력한다. 실증 규모(수십 명)에서는 감당한다.
- 삭제가 수동이라 절차서·접수 대장이 필요하다(L6, 별도).
- `collection_run` 중복 컬럼이 백필 전까지 남는다.

## 후속 / 미결정
- L1: 인앱 서비스 동의 기록·항목별 철회 조회(별도 ADR).
- L6: 수동 삭제 절차서·접수 대장, 사본 목록.
- 보관 날짜·data_policy 값 집합은 IRB 승인 뒤 사용자가 준다.
